# Setu Client

The frontend application for **Setu - Cloud-Backed File Sharing Platform**.
This project is built with React and Vite, serving as the user interface for high-speed file transfer, payload dispatch, and instant link sharing.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Key Technologies
- **React**: Component-based UI.
- **Vite**: High-performance dev server and bundler.
- **Tailwind CSS**: Utility-first styling.
- **Redux Toolkit**: Predictable state management.
